Porcentagem aparece em todo lugar: promoções, juros, impostos, pesquisas. Mas muita gente trava quando precisa calcular sem a calculadora na mão. Este guia cobre todos os casos com fórmulas simples e exemplos reais.

## O que é porcentagem?

A palavra "porcentagem" vem do latim *per centum* — "por cem". Percentagem é uma razão com denominador 100.

```
30% = 30/100 = 0,30
```

Isso significa que toda operação com porcentagem pode ser reescrita como multiplicação:

```
X% de Y = (X / 100) × Y
```

## Os 5 tipos de cálculo

### 1. Quanto é X% de Y?

O mais comum. Fórmula: `(X / 100) × Y`

**Exemplo:** Quanto é 15% de R$ 250?

```
(15 / 100) × 250 = 37,50
```

### 2. X representa qual % de Y?

Para descobrir a proporção. Fórmula: `(X / Y) × 100`

**Exemplo:** 45 é qual % de 180?

```
(45 / 180) × 100 = 25%
```

### 3. Variação percentual de X para Y

Para medir crescimento ou queda. Fórmula: `((Y − X) / |X|) × 100`

**Exemplo:** O produto custava R$ 80 e passou a custar R$ 96. Qual foi o aumento?

```
((96 − 80) / 80) × 100 = 20%
```

**Atenção:** O denominador é sempre o valor *inicial*, não o final. Esse é o erro mais comum.

### 4. Adicionar X% a Y

Para calcular acréscimos (juros, impostos). Fórmula: `Y × (1 + X/100)`

**Exemplo:** Preço de R$ 200 com 8% de imposto:

```
200 × (1 + 0,08) = 200 × 1,08 = R$ 216
```

### 5. Subtrair X% de Y

Para calcular descontos. Fórmula: `Y × (1 − X/100)`

**Exemplo:** Produto de R$ 150 com 20% de desconto:

```
150 × (1 − 0,20) = 150 × 0,80 = R$ 120
```

## Pegadinhas numéricas

### Aumentar 50% e depois reduzir 50% não volta ao original

Isso pega muita gente.

- Valor inicial: R$ 100
- Aumenta 50%: R$ 150
- Reduz 50%: R$ **75** ← não R$ 100!

Por quê? Porque o desconto de 50% é aplicado sobre R$ 150, não sobre R$ 100. A base mudou.

### Variação percentual não é comutativa

Se algo sobe 20% e depois cai 20%, você termina com **96%** do valor original, não 100%.

```
100 × 1,20 × 0,80 = 96
```

### "Desconto de 10% + 10%" não é 20%

Dois descontos sequenciais de 10% equivalem a um desconto de **19%**, não 20%.

```
1 − (0,90 × 0,90) = 1 − 0,81 = 0,19 = 19%
```

## Dica mental: o complementar

Para calcular 17% de um número, muitas vezes é mais fácil calcular 10% + 7%:

- 10% de 340 = 34
- 7% de 340 = 23,80
- 17% de 340 = **57,80**

Ou ainda: 20% − 3%.

- 20% de 340 = 68
- 3% de 340 = 10,20
- 17% de 340 = **57,80** ✓

## Resumo das fórmulas

| Operação | Fórmula |
|----------|---------|
| X% de Y | `(X / 100) × Y` |
| X é % de Y | `(X / Y) × 100` |
| Variação de X para Y | `((Y − X) / \|X\|) × 100` |
| Y + X% | `Y × (1 + X/100)` |
| Y − X% | `Y × (1 − X/100)` |
